## Concepts Practiced

## 1. Block-Level Elements

Practiced using elements such as:

* `<div>` — Groups content into sections.
* `<p>` — Displays paragraphs.
* `<h1>` to `<h6>` — Defines headings.
* `<section>` — Groups related content.
* `<ul>` and `<ol>` — Create lists.

### 2. Other HTML Elements

Explored elements such as:

* `<a>` — Creates hyperlinks.
* `<span>` — Groups inline content.
* `<strong>` — Highlights important text.
* `<em>` — Emphasizes text.
* `<br>` — Inserts a line break.
* `<link>` _ Links to CSS file.

### 3. Adding Images

Practiced displaying images using the `<img>` element.

Example:

```html
<img src="images/tacos.jpg" alt="An image">
```

The `src` attribute specifies the image path, while the `alt` attribute provides alternative text.
